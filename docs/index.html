The problem

Your Mac naps. Your run dies.

Idle sleep doesn't care that something important is still going. Coffee Shot orders a shot sized to the job, then wears off on its own — no indefinite toggle you forget about for three days.

Unattended agent runs

Coding agents work for hours without a keystroke. To macOS that looks exactly like nobody's home.

Builds and test suites

A clean build or a full suite that gets suspended halfway is an hour you spend again tomorrow.

Long transfers and renders

Overnight syncs, exports, dataset pulls. Start one before bed, come back to it finished.

The part that matters

It can't get stuck on.

The real failure mode of every keep-awake tool isn't failing to keep you awake — it's the opposite. A crashed or force-quit app leaves a power assertion behind, and your Mac quietly burns through the battery for a week.

Coffee Shot spawns caffeinate with -w <its own pid>. macOS itself tears the assertion down the moment the app goes away — crash, force quit, kill -9, doesn't matter. An orphan isn't unlikely here. It's structurally impossible.

Expiry is owned by the app's timer, not caffeinate -t — so the countdown in the menu and the assertion actually held can never drift apart.

That timer fires once, scheduled against a wall-clock date. No one-second tick waking the CPU 36,000 times per double shot to redraw an icon that hasn't changed. An app about power management has no business wasting it.

Don't take our word for it

Ask macOS what's keeping your Mac up, any time:

$ pmset -g assertions

The flags it holds

FlagAssertionEffect
-iPreventUserIdleSystemSleepNo idle sleep
-mPreventDiskIdleDisks stay spun up
-dPreventUserIdleDisplaySleepDisplay stays on — optional
-w <pid>—Dies with the app

-i works on battery too. Tools that use -s only take effect on AC power.

Install

One line. Then forget about it.

The installer builds from source on your machine instead of downloading a binary. That's deliberate: locally built apps are never quarantined, so there's no Gatekeeper warning to click through and no paid developer account propping it up.

Piping a script to bash deserves a read first — here it is, 77 lines.

  1. Requires macOS 13+ and the Xcode Command Line Tools — xcode-select --install. Nothing else.
  2. No Xcode, no package manager, no dependencies. The app is one Swift file, about 230 lines of AppKit.
  3. Uninstall is quit from the menu, then rm -rf "/Applications/Coffee Shot.app".
$ curl -fsSL https://raw.githubusercontent.com/arsalaniqbal-dl/coffee-shot/main/install.sh | bash

Prefer to pull it yourself?

$ git clone https://github.com/arsalaniqbal-dl/coffee-shot.git && cd coffee-shot && ./build.sh

Produces a universal, ad-hoc signed bundle. ./test.sh runs what CI runs.

One thing it can't do

caffeinate prevents idle sleep, not lid-close sleep. Shutting the lid still sleeps a laptop, Apple Silicon especially — no amount of espresso fixes that. Leave the lid open, or run clamshell with an external display.
